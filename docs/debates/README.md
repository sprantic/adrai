## Creating New Debates

1. Get next ID from `.deb-tracker.md`
2. Copy `templates/debate-template.md`
3. Save as `DEB-NNNN-topic.deb.md`
4. Update tracker
5. Update `.deb-graph.yaml` if blocking relationships exist

---

## When to Create a Debate

Any of these: **Disagreement** | **Irreversible** | **Uncertainty**

Everything else → Standard MR review
