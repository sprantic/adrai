## Naming Convention

```
DEB-NNNN-topic-name.deb.md
```

- `DEB-NNNN`: 4-digit zero-padded ID
- `topic-name`: kebab-case descriptive name
- `.deb.md`: File extension (distinguishes from regular markdown)

## Quick Commands

```bash
# Find next available ID
tail -1 docs/debates/.deb-tracker.md | grep -oP 'DEB-\d+'

# List all debates by status
grep -l "Status.*Active" docs/debates/DEB-*.deb.md

# Count debates by status
grep -rh "^> \*\*Status:\*\*" docs/debates/DEB-*.deb.md | sort | uniq -c
```
